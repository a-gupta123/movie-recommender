Choose a genre, mood, rating, or year range. The app turns those choices into a TMDB Discover search and shows popular matches.

This product uses the TMDB API but is not endorsed or certified by TMDB. GitHub Pages cannot run Flask, so this hosted demo uses HTML, CSS, and JavaScript to call TMDB from the browser. Your API key is saved only in this browser.
